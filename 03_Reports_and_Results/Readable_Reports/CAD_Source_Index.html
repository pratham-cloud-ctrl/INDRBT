CAD source and models

Project home · Illustrated mechanical tour · 54-part catalog · CAD method and validation

This folder contains ASTER-6's reproducible mechanical design and generated models: 54 components and six complete pose assemblies.

Inspect the robot online to orbit, move joints, adjust the gripper, isolate parts and play the task without downloading files. Native files and reproduction steps below are optional for offline inspection or editing.

Native-file and local-pack guide — open the actual STEP assembly, individual parts or FreeCAD model, understand their units/history and find the local inspection ZIPs. Consolidated public ZIP hosting is still pending; the guide states its status.

STEP, STL and FCStd links provide optional downloads for native inspection or editing. Use FreeCAD for the native model or STEP solids. After downloading on Windows, OPEN_FREECAD_MODEL.cmd opens the native assembly and OPEN_3D_VIEWER.cmd opens the offline browser viewer. PNG/SVG previews also display directly on GitHub.

Edit and regenerate

Authoritative source Role
config/robot.yaml Shared SI configuration for dimensions, joint poses and engineering assumptions
build123d/parameters.py Converts configured lengths from metres to CAD millimetres
build123d/geometry.py Constructs the component solids and their interfaces
build123d/assembly.py Applies the six joint-frame transforms
build123d/export_all.py Exports STEP/STL, local meshes and CAD measurements
freecad/inspect_step.py Independently imports assembly STEP files and generates the native FreeCAD inspection assembly

The Python geometry is parametric. The saved FreeCAD model is a solid export with inspection metadata, not the construction feature tree. For reproducible changes, edit the shared configuration or geometry source and regenerate. Save intentional manual FreeCAD edits under a separate filename; close older views without saving before replacing their generated file.

From 06_Complete_Project_Source, with the project's CAD dependencies, FreeCAD and Blender installed:

python scripts/generate_cad.py
python -m robotarm.demo --all
python scripts/refresh_cad.py

The final command refreshes native inspection, renders and CAD evidence. To audit saved outputs without regenerating them, run python scripts/review_cad.py. See the full workflow for tool discovery and overrides.

Coordinates and evidence

CAD lengths are millimetres; numerical kinematics use metres. Individual part files are authored in local groups base, j1 through j6. Open a complete assembly for positioned parts; assembly_meshes.json records local meshes and pose transforms. Motor, gearbox and bearing envelopes are simplified spatial representations with assumed materials.

CAD inspection, named-pose clearance and sampled-task clearance state what was checked. Drawings are concept interfaces rather than production drawings; geometric validity and sampled clearance do not establish hardware performance.
