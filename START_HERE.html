Open the CAD models

  1. For viewing: double-click OPEN_3D_VIEWER.cmd in this folder. It explicitly opens an installed browser, avoiding Windows file-association problems. Drag to orbit; use the wheel to zoom.
  2. For CAD editing: double-click OPEN_FREECAD_MODEL.cmd. It explicitly opens the assembled robot in the installed FreeCAD application. STEP and STL files are CAD/mesh data, rather than ordinary documents.
  3. For individual parts: use FreeCAD’s File → Open and select a file from 01_CAD_Models/STEP/Individual_Parts. Complete poses are under STEP/Assemblies.

Engineering scope

This is a digital engineering project with a conceptual PCB. Physical payload/repeatability, EMC, production suitability and full continuous collision verification are outside the verified scope. The browser viewer does not prevent collisions when manually changing joint angles.

Presentation folders contain verified copies of source artifacts. Regenerate outputs from 06_Complete_Project_Source, then refresh the organized copies. SHA-256 checks are recorded in ORGANIZATION_MANIFEST.json.
