PCB viewer

InteractiveHtmlBom provides component search, a correlated BOM and board drawing, and copper/net inspection. Its code is MIT-licensed. The generated viewer preserves the applicable credits; its bundled license is included with the PCB assets.

3D board display

The native KiCad board is exported as GLB and displayed using Google model-viewer, version 4.4.0, with its Apache 2.0 license. The module and model are served with the showcase, so browsing does not depend on a third-party model CDN.

Evidence and boundaries

The engineering source record identifies the source revision and retained check totals. The browser demonstration does not create new hardware performance evidence. A 4 kg payload and ±0.1 mm repeatability remain targets; structural and control results use the stated simplified models.

Native geometry and rule checks do not establish manufacturing qualification, EMC, functional safety, physical repeatability or continuous swept collision clearance. Manual robot poses may intersect. The circuit is a low-voltage interface for external control and drive hardware.
