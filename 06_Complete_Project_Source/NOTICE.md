# Third-party tools and library data

Original INDRBT source is MIT-licensed. Build123d, OpenCascade, numerical Python
libraries, FreeCAD, Blender and KiCad retain their own software licenses; their
installed binaries and library collections are not redistributed here.

The native schematic and PCB use stock KiCad community symbols, footprints and
available 3D models as design data. KiCad libraries use CC-BY-SA 4.0 with a design
and generated-file exception. This repository distributes an electronic design,
rather than a replacement library collection. See the official
[KiCad library license and exception](https://www.kicad.org/libraries/license/).
