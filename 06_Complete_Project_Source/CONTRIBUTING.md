# Contributing

From the organized repository root, enter `06_Complete_Project_Source`. Use Python 3.12 or later and install `python -m pip install -e ".[cad,dev]"`. Keep geometry, masses, motion constraints and demonstration settings in `config/robot.yaml`.

Format the changed source and run Ruff before regenerating evidence. Run `python scripts/run_validation.py` before proposing a change. `--full` also regenerates CAD/results and runs the complete native CAD/render/clearance refresh. That mode needs FreeCADCmd and Blender as well as KiCad; use `--freecad-cmd`, `--blender` and `--kicad-cli` to override discovery. [CAD reproduction](docs/04_cad.md#refresh-native-cad-evidence) explains the exact dependency order.

When package sources change, rebuild and install the wheel in a new isolated environment, then run `scripts/verify_wheel_install.py` from outside the checkout. When the generated viewer changes, run `scripts/verify_viewer.cjs` with Playwright and a browser. These checks bind their current sources/artifact; `--full` rejects stale retained browser/wheel evidence rather than inventing a pass. Native KiCad checks run before the saved-data gates. Use --skip-pcb-render only to retain existing PCB preview images while still executing fresh native electrical and fabrication checks; this does not skip ERC, DRC, connectivity or parity. The full source/input revision must remain unchanged during validation.

Claims must identify whether they are ASSUMED, TARGET, CALCULATED, SIMULATED or VERIFIED DIGITALLY. Record actual failures/fixes in the journal. A zero ERC count does not validate electronic component suitability or physical operation. Collision evidence must state its exact pair and sampling scope. Avoid adding an empty PCB or fabricated FEA/contact results.

After successful validation, run `python scripts/review_theory.py --pytest-xml results/validation/pytest.xml`, `python electronics/review_electronics.py`, `python scripts/update_report.py`, `python scripts/sync_presentation.py` and `python scripts/verify_presentation.py`. The numbered presentation folders and readable reports must match the authoritative source. Useful further extensions include continuous swept collision checks, coupled inverse dynamics and nonlinear/contact-aware gripper models. Hardware work is outside this digital project.
