The Python geometry is parametric. The saved FreeCAD model is a solid export with inspection metadata, not the construction feature tree. For reproducible changes, edit the shared configuration or geometry source and regenerate. Save intentional manual FreeCAD edits under a separate filename; close older views without saving before replacing their generated file.

From 06_Complete_Project_Source, with the project's CAD dependencies, FreeCAD and Blender installed:

python scripts/generate_cad.py
python -m robotarm.demo --all
python scripts/refresh_cad.py

The final command refreshes native inspection, renders and CAD evidence. To audit saved outputs without regenerating them, run python scripts/review_cad.py. See the full workflow for tool discovery and overrides.

Coordinates and evidence

CAD lengths are millimetres; numerical kinematics use metres. Individual part files are authored in local groups base, j1 through j6. Open a complete assembly for positioned parts; assembly_meshes.json records local meshes and pose transforms. Motor, gearbox and bearing envelopes are simplified spatial representations with assumed materials.

CAD inspection, named-pose clearance and sampled-task clearance state what was checked. Drawings are concept interfaces rather than production drawings; geometric validity and sampled clearance do not establish hardware performance.

The numbered 01_CAD_ModelsSource file folder contains organized copies for browsing. Regenerate here, then use the source project's presentation sync to refresh those copies.
